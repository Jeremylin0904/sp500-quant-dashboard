# 因子分析：Fama-French 五因子 + 動量
- **資料來源**：Kenneth R. French Data Library (monthly, USD)
- **五因子**：`F-F_Research_Data_5_Factors_2x3`（Mkt-RF, SMB, HML, RMW, CMA, RF）
- **動量**：`F-F_Momentum_Factor`（Mom / UMD）
- **因子資料區間**：1963-07 ~ 2026-03
- **回歸式**：`(R_strategy - RF) = alpha + b·[Mkt-RF, SMB, HML, RMW, CMA, Mom] + e`

## 因子定義與來源

| 因子 | 定義 |
|---|---|
| `Mkt-RF` | 市場超額：全美股市值加權報酬 − 一個月國庫券(RF) |
| `SMB` | Small-Minus-Big：小型股 − 大型股（規模） |
| `HML` | High-Minus-Low：高淨值市價比(價值) − 低(成長) |
| `RMW` | Robust-Minus-Weak：高 − 低營業獲利能力 |
| `CMA` | Conservative-Minus-Aggressive：低 − 高資產成長（投資） |
| `Mom` | Momentum/UMD：前 2–12 月贏家 − 輸家 |
| `RF` | 一個月美國國庫券利率 |

> 因子皆為 Ken French 官方月頻資料（百分比，已轉小數）。市場/規模/價值來自三因子；RMW、CMA 為五因子新增之獲利能力與投資因子；動量(Mom)為另一獨立檔案。
